📦 About TCV-ModMaster

TCV-ModMaster is the ultimate mod manager for The Choicer Voicer — a free, open-source tool that works on Windows, macOS, and Linux. Whether you want voice packs, studio themes, judge packs, or menu mods, TCV-ModMaster handles everything with a single click. It supports downloads from GameBanana and Nexus Mods, keeps your mods up to date automatically, and lets you switch between profiles to try different combinations without breaking your game.

Built for both beginners and experienced modders, this tool simplifies the entire modding experience. No need to manually download, unzip, copy files, or worry about conflicts. TCV-ModMaster does all the heavy lifting behind the scenes while giving you full control.

✨ Features

  • One-Click Install — Browse mods from GameBanana or Nexus Mods and install them instantly.
  • Auto-Updates — Mods update themselves in the background so you’re always using the latest version.
  • Profile Switching — Create different profiles for different playstyles or testing, and switch between them seamlessly.
  • Batch Operations — Install, update, or remove multiple mods at once with a few clicks.
  • Discord Integration — See mod updates, news, and community events directly in Discord.
  • Real-Time Toggling — Enable or disable mods without restarting the game or the manager.
  • Built-in Backup — Automatically backup your mod folder before making changes, so you can always go back.
  • Built-in Launcher — Launch The Choicer Voicer directly from TCV-ModMaster with your chosen mods active.
  • Mod Types Supported — Voice packs, studio themes, judge packs, menu mods, and more.

🚀 Quick Start Guide

  1. Download TCV-ModMaster from the link above.
  2. Run the application. On Windows, you may see a security prompt — click "More info" then "Run anyway" (the app is open-source and safe).
  3. Set up your game folder location (it usually detects it automatically).
  4. Browse mods from GameBanana or Nexus Mods using the built-in browser.
  5. Install any mod with one click. Create a profile first to keep your game organized.
  6. Launch The Choicer Voicer from within TCV-ModMaster and enjoy your modded game!

For detailed instructions, check the Help menu inside the application or visit the GitHub Wiki.

❓ Frequently Asked Questions

Is TCV-ModMaster safe to use?

Yes. The tool is fully open-source and has been reviewed by the community. It only modifies the game’s mod folder and does not change core game files.

Do I need an account for Nexus Mods or GameBanana?

No. TCV-ModMaster allows you to download content from both platforms without needing an account, though certain Nexus Mods files may require a free account to download.

How do I create a mod profile?

Inside TCV-ModMaster, go to the Profiles tab and click "New Profile." Give it a name, then select which mods you want active for that profile. Switch between profiles anytime.

Can I use TCV-ModMaster with other games?

No. TCV-ModMaster is specifically designed for The Choicer Voicer and will not work with other games.

What if I break something?

Don't worry. TCV-ModMaster automatically creates a backup of your mod folder before any change. You can restore from the Backups tab with one click.
